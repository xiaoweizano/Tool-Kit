## 1. 边界契约

### 范围(进 v0.1)

- **10 个工具全部进 v0.1**:租户 SQL 组装、JSON 解析、ID 生成、时间戳互转、md↔Word、SQL 占位符、正则生成、Linux 命令大全、Excel↔md、测试数据生成
- **应用壳**:线路图节点导航、首页总览(启动第一屏)、设置页、三主题(dark/paper/caramel,daisyUI 5)
- **扩展契约**:ToolDescriptor 接口 + 注册表;工具核心纯函数 transform + Web Worker(Comlink)统一传输路径
- **发布物**:Win(nsis)/Mac(dmg,ad-hoc)安装包 + GitHub Pages 在线版(同源静态部署);CI 双通道(ubuntu 测试 + win/mac 构建,Playwright smoke 守门)
- **检查更新**:GitHub Releases API 版本比对 + 引导 Releases 页

### 完成定义(质量口径)

十工具**同一工程口径**:spec(含 scenario)全过、纯函数 transform、golden 测试(含错误态与边界)、三态 UI(OK/ERROR/EMPTY,无静默失败)、粘贴即出(≤200ms 防抖)、一键复制(含失败回退)。

保真百分比**不是统一线**:md↔Word 按实测定线——常见结构(标题/列表/基础表格/图片)golden 锁定,复杂结构(嵌套表格/合并单元格)主动降级 + unsupported 提示;其余转换工具以 golden 锁行为即达标。

### 时间边界

无硬线。桌面版是产品本体,可先于在线版发布;服务器到期对 v0.1 无影响(在线版托管 GitHub Pages,免费、不到期)。

### 明确排除(不进 v0.1)

pandoc 高保真转换(v0.2 桌面增强)、AI 增强与跨设备同步(第二阶段)、代码签名证书、electron-updater 真自动更新、移动端专项设计、MiSans 品牌字体(系统 CJK 栈优先)、第 11+ 个新工具。
