## 实现期决策(0E interrogation + 评审修复,现已定,不再后置)
- **【评审修复 #1·P1·已批准 D8】Web 构建 CSP 放宽**:`src/renderer/index.html:6` 的 `connect-src` 白名单会在 CORS 之前拦死任意域请求(桌面走 IPC 不受影响)。修法(用户 2026-09-17 批准):`vite.web.config.ts` 加 `transformIndexHtml` 钩子,仅 Web 构建把 `connect-src` 放宽为 `*`;设计文档 premise 3 的降级话术同步覆盖 CSP 原因
- **【评审修复 #2】JWT 深链载荷**:响应 body 中有选中文本则发选中,否则发整个 body;JSON 解析深链固定发整个 body
- **【外部声音 P1·已批准 D9·推翻原修复 #3】env-resolve 编码规则**:env-resolve **原样文本替换,不做任何编码**(保证 `{{baseUrl}}` 这类完整 URL 变量不被破坏);编码责任只落在 URL query 参数编辑器:拼回时对「值」做 `encodeURIComponent`,对手改 URL 字符串的路径不做魔法
- **【外部声音 P1·已批准 D10】发送中可取消**:`ipcRenderer.invoke` 无法中断,新增 request-id + cancel IPC 通道(`net-fetch` payload 带 requestId,新增 `net-cancel` 通道,main 侧维护进行中请求的 AbortController Map);组件卸载时发 cancel
- **【外部声音 P2】httpFetch 改动按四层计**:`core/types.ts` → `preload.ts` → `main.ts`(超时+取消+控制器表) → `core/http.ts`,且**桌面路径当前根本没有超时判定**(仅 Web 分支有),任务需排在所有 UI 任务之前
- **【外部声音 P2】Web 降级话术补 mixed content**:GitHub Pages 是 HTTPS,请求 `http://` 内网目标会被浏览器按 mixed content 拦(不是 CORS),错误分类需单列
- **【外部声音 P3】sizeBytes 字节口径**:优先 `Content-Length`,缺失时按 UTF-8 字节数计(string length ≠ bytes)
- **【外部声音 P3】重定向可见**:响应面板显示最终 URL(`res.url`),与 curl 语义对齐
- **【外部声音 P3】深链载荷配额**:sessionStorage setItem 包 try/catch,超 5MB 时降级为只传选中文本
- **【评审修复 #4】cURL 导出方言**:v1 仅导出 bash 方言(Chrome「Copy as cURL (bash)」兼容),不做切换
- **【评审修复 #6】导入合并语义**:按 id 合并;同名集合/环境共存不覆盖
- **存储语义**:集合/历史一律存 `{{var}}` 模板原文,发送时才 resolve——切换环境后历史重发自动指向新环境(设计文档 schema 不变,补此语义)
- **深链传递机制**:sessionStorage 一次性载荷(`toolkit.deepLink.<targetToolId>`,目标工具挂载时读取即清);json-parser 与 jwt-tool 的 index 各加 ~5 行读取逻辑(跨工具小改,进 tasks)
- **URL 参数编辑器 × {{var}}**:query 值里的 `{{var}}` 原样保留,参数编辑器只在「非变量段」拆分拼回
- **cURL 边界**:`-F` → 明确报「v1 不支持 multipart」;`-d @file` → 报「不支持文件引用」;多个 `-d` → 拼接;`{{` 出现在 cURL 里原样保留(导入后走 env-resolve)
- **超时默认 15s,UI 可调**(5/10/15/30/60s),main 侧 AbortSignal.timeout 强制
- **worker 注册**:本工具无需 transform.worker.ts 注册(curl-parse/env-resolve 微秒级,非粘贴即转型工具);设计文档补显式声明防实现者猜
- **【S2/S4 路由到 opsx:explore 的细节默认值】响应体超 1MB 截断显示+完整复制;localStorage 配额溢出走错误三态不静默;发送中防重(按钮禁用+可取消)与组件卸载 abort;深链载荷含 token 属瞬时同源风险与 localStorage 等同(挂载即清)——以上按默认进 spec,exploration 阶段确认 golden 用例
